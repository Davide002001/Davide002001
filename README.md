## ⭐ Featured projects

### ⌚ [FiTagotchi](https://github.com/Davide002001/FiTagotchi) — watchOS game for an active lifestyle
A virtual pet for Apple Watch that turns physical activity into gameplay. HealthKit tracks steps and calories; activity earns coins to care for the pet, which reacts with SpriteKit animations (happy, tired, sleeping…). Includes a watch-face widget.

`Swift` `SwiftUI` `SpriteKit` `HealthKit` `WidgetKit` `watchOS`

### 🦻 [DeaField](https://github.com/Davide002001/DeaField) — sound awareness for deaf and hard-of-hearing users
iOS app that listens to the environment, recognises sounds with Apple's on-device sound classifier and alerts the user through haptic feedback.

`Swift` `SwiftUI` `SoundAnalysis` `AVFoundation` `Core Haptics` `iOS`

### 🌙 [Sleepy](https://github.com/Davide002001/Sleepy) — sleep data sync for iOS
iOS app that reads sleep data from HealthKit and synchronises it with a remote REST API, with clear success and error feedback in the UI.

`Swift` `SwiftUI` `HealthKit` `REST API` `iOS`

### 🍽️ [iOrder](https://github.com/Davide002001/Tech_Web_Project) — restaurant ordering & booking web app *(team project)*
Digital menu, cart, table booking and a reserved area where the owner manages orders, menu items and tables.

`HTML5` `CSS3` `JavaScript` `Firebase`

### 🌐 [Green Pass Network Service](https://github.com/Davide002001/Computer-networks) — client/server system in C
Distributed service with multiple TCP servers and clients to issue, verify, suspend and restore digital vaccination certificates.

`C` `TCP/IP` `POSIX sockets` `fork` `pthreads`
